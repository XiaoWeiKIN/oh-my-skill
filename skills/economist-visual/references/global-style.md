# 全局视觉规范 v2.1｜Economist-inspired

## 第一原则：编辑判断优先

清晰、准确、有观点的严肃编辑视觉语言；注重具象的经济/技术隐喻、字图关系、阅读路径和留白，不以红黑白套模板代替真正的设计。

**Visual richness is not visual clutter.** 主题物体、箭头、局部放大、图标或补充指标可以增强记忆和理解；禁止只为了「极简」删除已有效的视觉结构，也禁止为丰富而堆装饰。

## 基础色彩

- 深炭黑 `#202020`：标题、刻度、主要解释文本。
- 暖纸白 `#F7F6F2`：背景或中性区域。
- 编辑红 `#E3120B`：主张、重点数据、冲突或趋势；仅按语义使用。
- 蓝灰 `#54788C`：对照数据、次要变量。
- 中性灰 `#A5A5A5`：背景层、辅助轴线。

这是一套建议色板，并非 The Economist 官方设计规范。必要时为了数据分类和无障碍对比可补充颜色；不要为同一变量随意换色。

## 分层与排版

1. **Hook**：标题/概念隐喻，传达读图意义。
2. **Primary evidence/visual**：核心插画、机制关系或主要图表。
3. **Support**：有因果/信息价值的侧栏、注释或图标。
4. **Source**：仅在真实存在且适配数据时期时写来源。

标题可以大胆，但必须给核心视觉留空间；数据图里的文字不得遮挡轴、刻度、数据条。图面本身通常无需大段文字。一图一论点可容纳多个配角，而非强迫一个元素承载所有信息。

## 两种数据视觉语法

- **Editorial Infographic**：较高叙事表现力；可用红色柱形、增长趋势强调线、主题汽车等物件、独立要点栏；不要重复表达同一事实超过必要次数，不得给毫无数据意义的插画分配伪权重。
- **Editorial Data Graphic**：图表优先，标注、尺度与比较路径优先；插画淡化或移到图表外；不要求每幅都带图标、箭头或底部 KPI 卡片。

## 不可妥协的图形清晰度

- Plot exclusion zone（绘图区禁侵入区）：数据线、柱体、轴、图例、数据标签、刻度及其留白缓冲不可被汽车/图标/装饰物覆盖。
- 不强制固定 15/70/15 或统一多面板模版；根据文本、数据密度和画幅决定布局。
- 趋势箭头仅用于**编辑提示方向**，不得冒充独立实测曲线；优先与柱形分离，或以低视觉权重显示。
- 不使用不透明彩块、伪阴影、透视效果扭曲数值编码。

## 主视觉语言

可用纸上印刷、剪纸拼贴、简洁线条、几何色块、适量写实物体。避免赛博朋克、玻璃拟态、发光蓝紫、空泛齿轮与灯泡、无意义科技粒子、文字图标墙。

## 版权与真实性

仅借鉴通用编辑视觉设计语法；不复刻既有封面、未授权品牌 Logo、刊头、日期、页码、赞助信息。所有图中数字及其来源需满足 evidence-gate.md。
