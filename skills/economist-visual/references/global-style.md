# 全局视觉规范｜Economist-inspired

## 核心识别

追求《经济学人》式的**编辑判断**：大胆但可辩护的视觉论点、简洁构图、信息层级、带一点机智的概念隐喻、对比鲜明且克制的颜色。不要以「所有元素涂红黑白」替代真正的编辑设计。

## 视觉语汇

- **重点色**：编辑红 #E3120B；文字深炭黑 #202020；背景纸白 #F7F6F2；辅助蓝灰 #54788C；中性灰 #A5A5A5。上述是本 Skill 的建议配色，不宣称它们是官方品牌规范。
- **用色策略**：多数主体以黑、灰、纸白搭建；红色只强调冲突、变化、重点或焦点。科学符号和多变量可增加少量可辨色，不牺牲语义。
- **构图**：一个强视觉中心；充足留白；清晰对齐。文章配图不强制刊头；机制图不强制超大隐喻。
- **文字**：一句有分析性的标题；必要时少量短标签。不要添加伪造数据来源、伪造日期、英文碎片或长段落。中文排版必须易读。
- **图形**：二维编辑插画、丝网印刷般的色块、简洁线条、几何形、剪纸/拼贴质感、物体尺度反差、负空间；可少量用写实元素，但避免廉价图库与泛科幻渲染。
- **情绪**：冷静、审慎、略带讽喻，不制造无依据的恐慌和夸张。

## 避免的常见失败

霓虹赛博朋克、蓝紫渐变、玻璃拟态、3D 金属机器人、发光网格、毫无解释力的地球和灯泡、装饰性数据波形、营销标语、社媒缩略图式大字堆叠、拼贴大量小图标。

## 按场景调整

封面可以视觉化、戏剧化，文字极少；统计图应朴素且让数据优先；科学机制图可以细致但必须结构准确；地图必须保留地理语义。所有类型共享「克制、分析、清晰」，不共享僵硬版式。

## 原创性

借鉴的是严肃编辑视觉新闻的设计语言。不要生成真实的 The Economist 标志、红底白字刊头、虚构期号、现有封面复刻或让人误认为官方出品的版式。用户明确需要「封面感」时，使用虚构或无品牌的杂志化布局。
