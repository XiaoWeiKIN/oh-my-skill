# 杂志封面｜Magazine Cover

制作原创的新闻杂志封面概念，重点是概念张力、留白与缩略图辨识。

- 默认竖向 3:4；大而独立的主隐喻，标题少而有张力。允许戏剧性，但不靠杂乱路牌和虚构目录填充。
- 可以使用大胆尺度反差、反讽、物体错位或独特的象征物；文字应留有空间但不必处处写解释。
- 辅助颜色可随主题变化，并非永远红黑白；纸面印刷与少量写实可以共存。
- 不使用真实 The Economist 刊头、Logo、未经授权期号、文章页码、订阅价，不复刻已有封面。
- 示例：量子计算商业化困境可用「昂贵量子芯片与遥不可及的业务价值之间的物理隐喻」，不列出一整排障碍路牌；允许一个短标题和极少的副标题。
