# 科学机制图｜Scientific Explainer

在保证科学关系基本正确的前提下为非专家解释技术或自然机制。

- 首先列出输入、变换、输出与不可缺失的组件；保持结构、箭头方向与含义正确。
- 对 Transformer 注意力，准确区分输入 token、嵌入向量、Q/K/V 投影、权重归一化、加权求和；若只是高层示意，禁止假装完整架构。
- 公式仅在能够正确展示与检验时出现，不生成装饰性「似是而非」数学字符。
- 可以画剖面、分层、组件拆解、流程或多面板；优先保证标签清晰和关系准确，不为极简删掉必要组件。
- 标签简短，中文术语加英语缩写；必要时注「简化示意 / 非按比例」。
- 不画脑组织来类比 Transformer 的注意力结构，不用发光神经网替代真实关系。
