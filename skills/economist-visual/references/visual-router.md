# 视觉路由｜为主题选择画法

基于**用户想让读者理解什么**而不是关键词匹配；选择一种主图型，必要时加入一项次级元素。

| 主要任务 | 视觉类型 | 读取文件 |
| --- | --- | --- |
| 抽象议题、悖论、冲突、社会影响 | editorial-illustration | editorial-illustration.md |
| 明确要求杂志封面感、强编辑主张 | magazine-cover | magazine-cover.md |
| 解释流程、系统和运作路径 | visual-explainer | visual-explainer.md |
| 成本、激励、市场和反馈 | economic-diagram | economic-diagram.md |

| 贸易版图、产业地理、地缘依赖 | geopolitical-map | geopolitical-map.md |

## 决策顺序

1. 用户指定图型时尊重用户；若主题与该图型冲突，在画面中简化表达，或用一句话说明限制。
2. 主题的主要信息是否依赖**精确数字**？是：偏数据型；没有可靠数据：改概念对比，不伪造数值。
3. 是否依赖**真实地理位置或边界**？是：偏地图，先确认地理依据。
4. 是否必须让读者理解**真实技术内部结构**？是：偏科学机制图。
5. 是否是**经济因果和反馈**？是：偏经济机制图。
6. 是否是**流程与步骤**？是：偏解释型信息图。
7. 剩下的开放观点主题默认编辑插画；用户要封面时优先封面。

## 不明确时的默认

- 「AI 是否取代程序员？」→ 编辑插画（劳动分工与技能替代的张力）。
- 「Transformer 注意力机制」→ 科学解释图（token 与注意力权重的关系）。
- 「AI 单位成本下降为什么可能增加算力需求？」→ 经济机制图（需求反弹链条）。
- 「全球芯片供应链」→ 地缘地图或供应链解释图（依用户强调重点）。
- 「某国通胀率历史走势」→ 数据图（前提是有可靠数据）。
- 「给它做 Economist 封面」→ 杂志封面。

## 生成前的内部计划

记录：主题、单一视觉论点、图型、中心视觉元素、必需标签、事实依据、需要避免的误导、画幅。无需默认展示给用户。
