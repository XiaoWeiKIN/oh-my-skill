# Data Infographic｜旧入口兼容 / 数据图分流

此文件保留旧路由名称 `data-infographic`，避免既有调用失效。实际使用时**必须选择一个子模式**：

- `references/editorial-infographic.md`：传播、社交媒体、专题头图，允许有用的主题插画、趋势箭头和解释侧栏。
- `references/editorial-data-graphic.md`：报告和新闻正文，图表优先，优先准确比例、直接标签、无遮挡阅读。

共通硬规则：

1. 先执行 `references/evidence-gate.md`；没有合格数据，不画有数字刻度的假图。
2. 与上一版本对照时执行 `references/edit-preservation.md`，锁定用户喜欢的图型与有信息功能的视觉要素。
3. 统计图不可制造假来源、2025 数字不得默认归属于 2024 版报告。
4. 生成模型对坐标不提供精确保证；复杂真实数据应优先寻求确定性制图，而不是在没有校验的情况下把生成图称为统计证据。
5. 通过 P0/P1/P2 三级验收，尤其排查主题插画遮挡数据和数据条与坐标不一致。
