# Evidence Gate｜绘制前的事实准入与出处管理

## 目的

将可视化主张与数据来源分离。在生成模型接触任何精确数字前，判断它是否**允许出现在画面中**。任何颜色、漂亮的线条或脚注都不能替代证据。

## 内部 Evidence Manifest（最小结构）

对每个定量序列或结论记录：

```yaml
claim_id: ev_sales_global_2025
claim: "2025 年全球 EV 销量"
value: null                      # 缺少可验证数据则为 null
unit: "million vehicles"
period: "2025"
coverage: "global"
definition: "BEV + PHEV"       # 口径必须明确
status: "unverified"            # verified | user_provided | illustrative | unverified
source_title: null
source_date: null
source_url: null
approved_label: null             # 未通过不得写入图
```

## 准入判定

- `verified`：来自可核验且与对应年份、地区、统计口径一致的来源，可在画面里引用，并在生成后复核。
- `user_provided`：用户给定的明确数据，允许按**用户提供数据**标注，但不得擅自补一个第三方来源或称已经独立核实。
- `illustrative`：仅用于假设性说明；必须标注「示例 / 非实测」，不能让假数看起来像真实市场统计。
- `unverified`：不得画成实测图，不得补来源、数字和精确轴。可改做定性的概念图或要求数据。

## 数值表绘制条件

含年份及真实坐标的趋势图，必须具备：指标定义、单位、覆盖范围、各年份数值、来源或用户数据声明；来源发布时间与数据年份相容。只有个别里程碑数值时，不得自动补齐连续年份柱形。

**特别禁止**：

- 编造 2010—2025 逐年销量以填满 16 根柱子；
- 用 2024 年出版的 IEA 报告冒充 2025 年已发布实际销量数据来源；
- 以「大约」回避来源缺失；
- 用某地理市场份额补成全球份额；
- 年增长倍数和起点四舍五入数值相除后不一致；
- 将编辑箭头的几何曲率伪装成量化数据。

## 渲染与验证边界

生图模型可能不遵守精确数字、尺度、比例，即使已给合法来源。必须**人工可验证地**比对柱高、刻度、文字；不确定时说明限制并重做简化版本。出版级真实图表应由可复现代码绘图，并对图片做后续视觉审核；这是另一个工具职责，不能假装本 Skill 已完成。

## 图中的来源标签

仅当 `source_title/source_date` 真实且适用于数据时期时写，禁止模型自造 IEA、SEMI、IMF、WTO 等来源。若仅有用户数据，标注「数据：用户提供」而不是虚构机构来源。
