# 中文生图 Prompt 组装协议

此文件是 Agent 的最终生图指令生成规范，不是让用户每次手动拼接的模板。默认内部使用中文；需要时保留艺术术语的英文对应。

## 必填顺序

1. **创作目标**：图片给谁看、用于什么、要解决什么问题。
2. **中心论点**：一句话说清画面要表达的关系/冲突/机制；不添加未证实事实。
3. **图型与画幅**：由路由决定；默认横向 16:9，封面默认竖向 3:4。
4. **构图与视觉主体**：描述具体对象、相对位置、动作、大小关系、阅读方向。
5. **必须出现的内容**：关键实体、标签、箭头、数字及其来源约束；用明确的短列表。
6. **全局风格**：Economist-inspired 严肃编辑插画/数据新闻气质，克制红、炭黑、纸白和辅助蓝灰，留白与信息层级。
7. **负面约束**：排除泛科幻、营销海报、文字堆积、无意义图标、虚构数据、假刊头。
8. **出图自检点**：具体最容易出错的标签、方向和比例。

## 中文完整模板

请创作一张原创的、受《经济学人》视觉新闻传统启发的{视觉类型}。
主题：{主题}。
面向读者：{受众}。用途：{用途}。
核心视觉论点：{一条可辩护的主张或解释性问题}。

画面构图：{主体对象、隐喻、关系、层次、留白、阅读方向}。
必须表现的内容：{逐项明确，最多 3—6 项}。
标题：{短中文标题；不需要文字则写无标题}。
短标签：{逐项列出；无则写无}。
事实边界：{已确认数据、简化示意要求、禁止臆造的部分}。
比例和尺寸：{16:9 / 3:4 / 用户指定}。

视觉风格：严肃而有洞见的编辑视觉设计；纸白 #F7F6F2、深炭黑 #202020、少量编辑红 #E3120B，蓝灰只作辅助；简练线条、清楚排版、视觉隐喻有明确语义，避免装饰性元素。

不要：官方 Economist 商标或仿冒刊头；已有封面复刻；霓虹、发光电路、科技图库、3D 噱头、密集文字、无关图标、假数据、假来源、错字或伪英文。

生成后重点检查：{本主题最脆弱的 2—4 个事实、结构、数值或文字点}。

## 类型附加约束

- **封面/插画**：强化隐喻与主体；取消不必要的箭头和标签。
- **解释/科学/经济机制**：明确组件、方向与关系；有必要时明确「简化示意」。
- **数据新闻**：完整指定数据、尺度、单位与序列；如无法验证精确性改概念呈现。
- **地理**：没有真实坐标或边界依据时，采用「区域关系示意」而不是精确地图。

## 生成后重试用中文修复提示词

保留原图已经正确的{构图与主体}，仅修正以下问题：{逐项具体问题}。
避免引入新文本、新数字或新图例。再次遵守 Economist-inspired 的克制编辑视觉语言与原始事实边界。

## 两种默认行为

- 用户说「给我一张图」：实际调用可用的生图模型，交付图片，不只输出模板。
- 用户说「给我提示词」：返回已经填好主题内容的完整中文生图 Prompt，不把变量占位符留给用户。
