# Prompt Template v2.1｜设计指令协议

生图前在内部形成 `visual_argument`、`visual_mode`、`evidence_manifest`、`keep/repair/forbid_new`、`approved_text`、`plot_exclusion_zone`。

## 组装顺序

1. 用途与读者 + 单一编辑论点。
2. 主类型 + 数据模式（如适用）+ 画幅。
3. 主视觉对象、布局、各区域与阅读顺序。
4. **必须保留的成功要素**（原图优化时）。
5. 已准入的数字/短标签**白名单**，不可出现其它数字/机构/页码。
6. Plot exclusion zone：具体说明数据条、轴、刻度、图例的保护区域，以及插画允许出现的安全区域。
7. 颜色、字体、质感、红色强调职责。
8. 本主题 P0/P1 风险与负面约束。

## 中文生图指令模板

创作一张独立原创的 Economist-inspired 严肃编辑视觉图。用途：{用途}；读者：{受众}；画幅：{画幅}；语言：{语言}。
唯一视觉论点：「{主张}」。视觉类型：{类型}；数据子模式：{如有}。

主体布局：{对象、图形、方位、层级、边缘空白}。
必须保留：{参考图已成功的元素；新图则无}。
允许改动：{必须修复的错误；新图则无}。
图表类型锁定：{如 bar / line / 无}。
批准的图片文字/数字：{完整白名单；每个值标明单位/年份/来源状态}。
事实边界：{来源、统计口径、假设条件、概念示意标记}。

绘图区禁侵入：{定义柱体/曲线/轴/刻度/图例所处矩形及缓冲区}。所有主题物件只能放在{独立安全区域}，不得覆盖任何数据编码或标签。核心图表必须在缩小观看时也能清晰阅读。

视觉风格：深炭黑、暖纸白、克制编辑红与蓝灰；大而清晰的编辑标题、数据节奏与适量有意义的视觉插画。追求 visually compelling **且** information-safe，不以无意义删除元素追求极简。

不得生成：官方刊头、虚构日期、页面编号、未批准的数值与机构、虚构统计曲线、霓虹与无关图标；不得默默将有效柱形改面积图。

验收重点：{按 P0、P1、P2 指定 3—6 个风险点}。

## 两种模式的增量描述

- `Editorial Infographic`：鼓励有节制的强叙事，允许一条编辑方向提示箭头和主题插画（图表外），标题与侧栏可以更丰富。
- `Editorial Data Graphic`：强调精确年份、轴与直接标签；主题插画最小化，不牺牲绘图区给装饰。

## 修复提示词模板

以当前图为基准，只修复：{精确错误位置和改法}。必须原样保留：{已成功的主图型、颜色、排版、主体、经核准文字}。不得添加任何新数字、来源或出版信息。修复后检查图表区无遮挡以及标签/单位/数值与来源相符。
