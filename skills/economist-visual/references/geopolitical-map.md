# 地缘政治与地理视觉｜Geopolitical Map

## 任务

当空间分布、跨境依赖或地理流向是中心信息时，生成经济学人式地理新闻图。

## 设计指令

- 先明确图的角色：位置分布 / 供应链节点 / 跨境联系 / 区域比较。
- 仅标注有依据的国家、地区、城市、流向和节点；不知道的位置不凭印象补充。
- 统一图例、符号和颜色含义。箭头表示真实方向，不是纯装饰。
- 当精确边界、海岸线或投影无法由生图模型可靠呈现时，使用**明确标为示意**的简化地理拓扑或区域块图，不输出伪精确地图。
- 争议边界不擅自做主权结论，必要时用中性表达和明确的地理范围说明。
- 蓝灰突出一般关系，红色突出某个战略瓶颈、集中度或依赖点。

## 避免

伪造地图坐标、错误边境、重复或丢失国家、无依据的物流箭头、随意标注贸易份额、将世界地理画成只由几个大国组成的事实图。

## 中文生图指令片段

生成一张经济学人式地理解释图，主题「{主题}」。强调「{真实位置或连接关系}」，采用「{世界/区域/拓扑示意}」。标清关键地区、方向和图例，纸白底、蓝灰区域与一处编辑红重点。若缺少精确地图依据，在图上标注「地理关系示意」，不得虚构数字或边界。
