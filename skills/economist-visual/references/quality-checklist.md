# Quality Checklist v2.1｜分级检查、阻断交付与定向修复

每张图单独验收；不能凭漂亮的视觉观感宣布事实正确。检查失败后**只修具体问题**，不要无目的重生。

## P0｜必须阻断交付：真实性与安全

- 虚构或没有来源的具体统计值、增长倍数、来源机构、引用与预测日期。
- 已经确认的数值与画面矛盾（柱高、刻度、数值、份额加和、年份缺失）。
- 科学公式、结构、因果方向错误；错误地理边界或物流路径被当作事实。
- 冒充官方 Economist 刊头、现有封面、虚构杂志日期与页码。
- 用户提供的精确术语、数据、标签被擅自更换。

处理：删除不合格细节，改成明确「概念示意」，或基于可靠输入重新渲染。**不能只加一条很小的免责声明继续交付伪数据图。**

## P1｜必须修复：图表与阅读

- 汽车、充电桩、图标、人物覆盖任何主要柱体、坐标轴、关键刻度或标签。
- y 轴尺度不足以解释最大值；尺度、单位、年份、图例不一致。
- 标题、文字重叠、裁切、错字、无意义英文；缩略图看不清主要论点。
- 趋势箭头与数据线混淆；箭头方向导致错误趋势印象。

处理：移动主体物件到安全区域、扩大绘图区、缩减次要侧栏、减少文本；**不要默认换图型或删掉用户喜欢的主题插画**。

## P2｜优先改进：编辑视觉

- 缺少一眼可读的论点；主视觉平淡、过度模板化、缺少节奏。
- 用红色强调过多，使主要发现失焦。
- 侧栏与底部 KPI 重复讲同一件事；装饰图标没有语义功能。
- 优化后视觉冲击力明显降低，而没有对应的阅读或事实收益。

处理：恢复图形层次、合理强化红色、加回有解释力的主题物体、重排信息；不要仅以减少元素衡量质量。

## 输出前检查矩阵

| 检查项 | 必须满足 |
| --- | --- |
| 类型路由 | 与目标受众和用途吻合 |
| 图中事实 | 通过 Evidence Gate 或明确概念性质 |
| Plot exclusion zone | 核心图表与标签无遮挡 |
| 保留式改图 | Preservation Contract 关键元素未丢 |
| 文字 | 逐字审查可读性与合法来源 |
| 品牌 | 无未经授权的官方刊头、虚构期号 |
| 视觉效果 | 有信息层级、语义丰富且无无意义装饰 |

## 修复协议

1. 记录 `failed_checks`，每条明确指出**位置 + 错误 + 正确要求**。
2. 保留通过的结构、图型、主色、主体与文案。
3. 一次修复尽量只解决一类问题，出图后重跑 P0/P1。
4. 若无法确保精确数值，不得假称「已核对」。停止生成精确统计图并说明界限。

注：这是一套生成时的检查规约，不等于具备自动 OCR、数据校验器或正式审计能力。
