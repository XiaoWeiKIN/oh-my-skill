# Economist Visual｜编辑型生图 Skill

## 使命

将一个主题转译为具有《The Economist》视觉新闻气质的**原创视觉论点**：克制、简洁、分析性强，有鲜明的信息层级，而非普通 AI 科幻海报。所有图形由**生图模型**生成；不要默认调用 Mermaid、Matplotlib、SVG/Python 绘图或网页排版工具。

## 必须执行的流程

1. **理解任务**：识别主题、受众、用途、画幅、输出语言及用户给出的数据、事实、图片。未指定时，默认中文、16:9 横图、面向受过高等教育的非专业读者。
2. **提炼论点**：确定读者看图后应理解的一个问题、反差、机制或趋势。不要凭空加入未经证实的断言。
3. **选择图型**：读 references/visual-router.md；选择一种主要图型，必要时只借用其他图型的次级元素。
4. **加载规范**：必读 references/global-style.md 和对应图型文件；设计科学/统计/地图类作品时同时考虑事实边界。
5. **编写中文生图指令**：按 references/prompt-template.md 将主题、视觉隐喻或机制、版式、必要文字、配色、限制项组合成一份具体可执行的指令；默认提示词中文。
6. **实际生图**：使用当前环境可用的图像生成工具直接出图。用户明确仅要 prompt 时才只返回 prompt。工具缺失时清楚说明，不得声称已生成图。
7. **核验与修正**：读 references/quality-checklist.md；检查风格、文字、机制、数据与构图。发现具体错误时针对错误编辑或重生，避免无目的反复生成。
8. **交付**：优先交付图片，必要时用 1—2 句说明视觉论点、概念性数据或未核实内容。不向用户倾倒内部工作流。

## 核心约束

- **固定 Economist-inspired 风格**，不是通用制图 Skill。借鉴分析型视觉新闻的构图、隐喻、留白、标题和克制配色，不复刻已存在的封面，也不默认使用其商标、刊头或假期号信息。
- **一图一主张**。图形表达应明显，而非靠密集小字才能理解。允许多面板，但必须服务同一问题。
- **按图型变换语法**。封面偏象征隐喻；信息图偏结构、箭头与注释；统计图偏证据、尺度和对比；机制图偏准确关系。不得要求全部图片都像封面。
- **图像生成的精度边界**：真实数字、坐标、引文、地图和科学结构只有在提供可靠依据并可核验时才可表现为精确事实。生图模型可能画错；不应把生成结果直接当作科研绘图或统计证据。无可信数据时改用显式「概念示意」而非伪造统计图。
- **文本与语言**：默认图中文字为简体中文；必要时保留专业英文缩写；文字要少且必须逐字检查。标题原则上不超过 16 个汉字，标签尽量短。
- **安全与真实**：不要将未经证实的立场、推测或虚构数据包装成事实；对争议话题区分事实与观点；避免假冒官方刊物封面。

## 推荐输出模式

- **直接生图（默认）**：理解主题 → 生图 → 验收 → 交付。
- **只生成生图提示词**：用户明确要求 prompt 时输出完整、可复制中文指令，不调用生图。
- **改图**：有原图时保留主体、构图约束和正确内容，仅编辑用户要求的区域；修正乱码或错误标签。

## 完成标准

读者无需查看长篇说明，即可识别主题与主视觉论点；细看能理解关键机制、比较或冲突；图中文字清楚；无假数据、无杂乱装饰、无未经授权的官方品牌外观。
