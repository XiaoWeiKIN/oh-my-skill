# Changelog

## 2.1.0 — Editorial richness + evidence safety

- 新增 `editorial-infographic.md` 与 `editorial-data-graphic.md` 双数据图模式。
- `data-infographic.md` 保留旧路由兼容。
- 新增 `evidence-gate.md`：数据源、统计口径、验证状态、年度一致性。
- 新增 `edit-preservation.md`：修改前固定成功元素与图型，定向修复。
- `global-style.md` 采用 "Visual richness is not visual clutter"；解释箭头、主体插画、侧栏与数据各自职责。
- `quality-checklist.md` 改为 P0/P1/P2 分级，P0/P1 错误阻断交付。
- 更新 Prompt 组装协议与六类设计规则，新增 EV 双模式与量子封面回归示例。
- 新增 `tests/regression-cases.md`；测试规范尚未在目标模型自动执行。

该版本通过独立 PR 提交 GitHub 仓库。可将包内的 `SKILL.md`、`references/`、`examples/`、`agents/` 替换到仓库对应 skill 目录。
